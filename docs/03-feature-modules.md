## 2. 热点输入与发现

功能点：

- 手动输入热点主题、关键词、链接、行业、地区。
- 批量导入关键词或候选主题。
- 设置时间窗口：24 小时、7 天、30 天、自定义。
- 调用搜索、网页抓取、社媒/社区接口获取候选热点。
- 对相似内容做聚类，合并重复热点。
- 生成热点摘要和候选机会。

页面元素：

- 热点搜索框
- 数据源筛选器
- 热点趋势列表
- 热度趋势小图
- 证据数量和可信度提示

## 3. 证据包

功能点：

- 自动保存搜索结果和抓取页面为 EvidenceItem。
- 支持网页正文提取、摘要、标签、可信度评分。
- 支持人工添加证据链接或上传文件。
- 支持标记证据为无效、重复、低可信。
- 支持报告引用证据。

证据可信度建议：

- 官方/一手数据：高
- 主流媒体/行业报告：中高
- 社媒帖子/社区讨论：中
- 未知来源/营销软文：低

## 4. 热点评估

功能点：

- 自动计算 `TrendScore` 和 `OpportunityScore`。
- 展示评分分解和证据支撑。
- 输出反证与风险。
- 支持人工调整评分并记录理由。
- 支持将机会标记为“观察、调研、原型、放弃”。

评分建议：

| 分数 | 含义 | 动作 |
| --- | --- | --- |
| 80-100 | 高潜机会 | 进入深入调研或快速原型 |
| 60-79 | 值得观察 | 补充证据或小规模验证 |
| 40-59 | 不确定 | 暂缓，等待更多信号 |
| 0-39 | 低价值/高风险 | 归档或放弃 |

## 5. 市场价值调研

功能点：

- 竞品识别与表格化对比。
- 商业模式建议。
- 市场规模粗估和假设记录。
- 用户画像和付费意愿分析。
- 渠道和增长路径分析。
- 输出市场调研报告。

关键产物：

- 竞品矩阵
- 市场假设清单
- 目标用户画像
- 差异化切入点
- 进入/不进入建议

## 6. 需求分析

功能点：

- 将市场机会转为 PRD。
- 自动拆分 MVP、V1、V2。
- 生成用户故事和验收标准。
- 生成功能优先级和任务拆分。
- 支持人工编辑和版本管理。

PRD 必须包含：

- 背景和目标
- 目标用户
- 使用场景
- 功能范围
- 非功能要求
- 验收标准
- 埋点指标
- 不做范围

## 7. 设计策划

功能点：

- 信息架构和页面清单。
- 用户流程图。
- 页面文案草案。
- 视觉方向和素材需求。
- 可选：生成低保真原型或前端页面。

质量要求：

- 不输出空泛设计描述，必须落到页面、流程、组件、状态。
- 设计方案必须与 PRD 功能范围一致。

## 8. 开发执行

功能点：

- 技术方案生成。
- API、数据库、模块边界设计。
- 任务拆分和开发顺序。
- 沙箱代码生成与运行。
- 支持构建日志和错误修复。

开发门禁：

- 明确运行方式。
- 明确环境变量。
- 至少通过基础构建或关键测试。
- 产物可下载或可预览。

## 9. 测试验收

功能点：

- 自动生成测试计划。
- 自动生成单元测试、接口测试、前端冒烟测试建议。
- 运行测试并保存结果。
- 生成发布验收清单。

测试报告包含：

- 测试范围
- 测试结果
- 失败项
- 已知问题
- 发布建议

## 10. 运营增长

功能点：

- 上线计划。
- 渠道实验。
- 内容日历。
- 转化漏斗指标。
- 运营复盘。

运营实验格式：

- 假设
- 渠道
- 目标人群
- 内容/活动
- 成本
- 指标
- 复盘结论

## 11. 客户管理

功能点：

- 线索记录。
- 客户分层。
- 反馈记录。
- 需求请求转化。
- 跟进任务。

MVP 可以先只做轻量 CRM，不做完整销售系统。

## 12. 舆情分析

功能点：

- 监控正负面反馈。
- 聚类投诉主题。
- 识别高风险舆情。
- 生成响应建议和话术。
- 将产品问题回流到需求池。

舆情级别：

| 级别 | 含义 | 处理 |
| --- | --- | --- |
| P0 | 法律/安全/大规模负面传播 | 立即人工介入 |
| P1 | 明显负面增长或核心用户投诉 | 当日处理 |
| P2 | 局部负面或功能抱怨 | 纳入迭代 |
| P3 | 普通反馈 | 观察 |
