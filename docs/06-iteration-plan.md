# Gem Cutter 开发迭代规划

## 1. 迭代策略

Gem Cutter 的研发应优先验证“热点 -> 评估 -> PRD -> 原型/开发”的主链路，暂缓复杂数据源和完整 CRM。原因是最大风险不在 UI，而在 Agent 是否能稳定产出有证据、可执行、可复盘的商业判断和项目产物。

建议采用 5 个阶段：

1. P0：架构骨架与文档确认。
2. P1：MVP 研究评估链路。
3. P2：产品策划与开发执行链路。
4. P3：运营、客户、舆情闭环。
5. P4：SaaS 化、插件化和规模化。

## 2. P0 架构骨架

周期：1 到 2 周。

目标：

- 初始化项目结构。
- 确认技术栈。
- 建立 Agent Runtime 基础。
- 建立基础数据库 schema。
- 建立文档和规范。

任务：

- 创建后端 FastAPI 项目。
- 创建前端 React + Vite 项目。
- 设计 `harness` 与 `app/domain` 分层。
- 接入基础 LLM 配置。
- 实现线程、运行、SSE streaming 的最小版本。
- 本地开发先使用 SQLite 关系表；Postgres、Redis、MinIO 作为生产化阶段再引入。
- 编写基础 CI：lint、test、typecheck。

交付物：

- 可启动的前后端骨架。
- 可运行一次 Agent 对话。
- 数据库迁移脚本。
- 项目 README 和本目录文档。

验收：

- 本地一条命令启动基础服务。
- 前端可以发送消息并收到流式响应。
- 后端可以保存 AgentRun。

## 3. P1 MVP 研究评估链路

周期：2 到 4 周。

目标：

- 支持用户输入热点主题。
- 自动完成证据收集、热点评分、商业可行性初评。
- 生成可追溯 Markdown 报告。

任务：

- 实现 Topic、EvidenceItem、Opportunity、EvaluationReport。
- 实现 Web 搜索/网页抓取工具。
- 实现 EvidenceService。
- 实现 HotspotScoutAgent、TrendEvaluatorAgent、MarketAnalystAgent 初版。
- 实现评分 schema 和证据引用校验。
- 实现机会详情页和报告面板。
- 实现机会状态：draft、evaluating、researching、archived。

交付物：

- 热点初筛报告。
- 证据包。
- 评分卡。
- 机会看板。

验收：

- 输入一个主题后，系统可生成不少于 3 条证据的评估报告。
- 报告中关键结论包含证据引用或明确假设标记。
- 用户可以选择“继续调研”或“归档”。

## 4. P2 产品策划与开发执行链路

周期：3 到 6 周。

目标：

- 将通过评估的机会转成 PRD、设计方案、开发任务和可运行原型。

任务：

- 实现 PMAgent、DesignArtAgent、DevAgent、QAAgent。
- 实现 ProductProject、Artifact、TestRun。
- 实现 PRD 生成和版本管理。
- 实现设计说明和页面流程生成。
- 实现沙箱代码生成、构建、测试。
- 实现测试计划和发布门禁。
- 前端增加项目空间、任务列表、产物预览。

交付物：

- PRD 文档。
- 设计说明。
- 技术方案。
- 原型或代码产物。
- 测试报告。

验收：

- 通过评估的机会可以一键创建 ProductProject。
- 系统能生成 MVP PRD 和任务拆分。
- 至少支持一种项目类型的原型生成，例如 Web 工具页。
- 测试报告能标明通过/失败/已知问题。

## 5. P3 运营、客户与舆情闭环

周期：3 到 5 周。

目标：

- 上线后收集客户反馈和舆情信号，回流到需求池。

任务：

- 实现 Customer、CustomerFeedback、Campaign、SentimentSignal。
- 实现 OpsAgent、CRMAgent、SentimentAgent。
- 支持人工导入客户反馈。
- 支持外部链接/搜索结果作为舆情信号。
- 实现运营计划和实验复盘。
- 实现负面舆情分级和处理建议。

交付物：

- 运营计划。
- 客户反馈列表。
- 舆情报告。
- 需求候选回流。

验收：

- 客户反馈可以转为需求候选项。
- 舆情信号可以标记 P0-P3。
- 运营实验可以记录目标、渠道、指标和复盘。

## 6. P4 SaaS 化与规模化

周期：持续迭代。

目标：

- 支持多用户、多团队、多数据源、高并发任务和插件生态。

任务：

- 多租户权限。
- 数据源市场和 MCP 配置 UI。
- 插件化评分模型。
- 行业模板。
- 成本预算和配额。
- 大规模趋势数据分析。
- 审计与合规报表。

交付物：

- 团队空间。
- 权限体系。
- 插件管理。
- 高级分析看板。

验收：

- 不同团队数据隔离。
- 支持配置不同 Agent、Skills、数据源。
- 支持查询任务成本和调用审计。

## 7. 里程碑概览

| 里程碑 | 周期 | 主要价值 |
| --- | --- | --- |
| M0 架构骨架 | 第 1-2 周 | 项目可运行 |
| M1 热点评估 MVP | 第 3-6 周 | 可判断机会 |
| M2 PRD 与原型 | 第 7-12 周 | 可推动开发 |
| M3 运营闭环 | 第 13-17 周 | 可持续迭代 |
| M4 SaaS 扩展 | 第 18 周后 | 可商业化交付 |

## 8. 优先级建议

最高优先级：

- 证据包
- 评分模型
- 报告生成
- 阶段门禁
- PRD 生成
- AgentRun 审计

中优先级：

- 自动热点雷达
- 设计原型
- 沙箱开发
- 测试自动化

后置：

- 完整 CRM
- 多平台舆情实时监控
- 多租户计费
- 插件市场
